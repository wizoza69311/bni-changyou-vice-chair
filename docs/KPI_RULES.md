# BNI 長佑分會 KPI 規則

本文件記錄副主席管理系統目前採用的 KPI 與紅綠燈計算規則。規則異動時應同步更新本文件及系統計算程式。

## 統計期間

- 出席、培訓與夢幻引薦金額：包含當月的連續六個月。
- 例如 8 月統計 3–8 月；進入 9 月後改為 4–9 月。
- 當月即使只有第一週資料，仍立即納入統計。
- 來賓：最近四週。
- 一對一與內外部引薦：依統計期間換算每週平均。

## 出缺席規則（最高 20 分）

| 折算缺席次數 | 分數 |
| --- | ---: |
| 0 次 | 20 |
| 1 次 | 15 |
| 2 次 | 10 |
| 3 次以上 | 0 |

### 遲到折算

- 滾動六個月內，每 2 次遲到（L）折算 1 次缺席（A）。
- 第 1、3、5 次遲到仍顯示 `L`。
- 第 2、4、6 次遲到顯示 `L/A`，表示該次遲到已完成一次缺席折算。
- 折算後的缺席會計入右側缺席總數。

| --- | ---: |

| 最近四週來賓人數 | 分數 |
| --- | ---: |
| 0 位 | 0 |
| 1 位 | 10 |
| 2 位以上 | 15 |

## 一對一會面（最高 15 分）

| 每週平均次數 | 分數 |
| --- | ---: |
| 0 | 0 |
| 0.5 | 5 |
| 1 | 10 |
| 2 以上 | 15 |

## 內外部引薦（最高 20 分）

| 每週平均次數 | 分數 |
| --- | ---: |
| 少於 1 | 0 |
| 1 | 5 |
| 大於 1、1.2 以下 | 10 |
| 大於 1.2、2 以下 | 15 |
| 大於 2 | 20 |

> 系統邊界採：剛好 `1` 為 5 分、剛好 `1.2` 為 10 分、剛好 `2` 為 15 分。

## 夢幻引薦金額（最高 15 分）

| 六個月金額 | 分數 |
| --- | ---: |
| 40 萬以下 | 0 |
| 41–80 萬 | 5 |
| 超過 80 萬、未滿 200 萬 | 10 |
| 200 萬以上 | 15 |

> 系統將剛好 200 萬歸入 15 分級距。

## 總分燈號

| 總分 | 燈號 |
| --- | --- |
| 70–100 | 綠燈 |
| 50–69 | 黃燈 |
| 30–49 | 紅燈 |
| 0–29 | 黑燈 |

## 資料完整性原則

- 未取得的 PALMS 或活動資料不可直接視為 0 分。
- 缺漏資料應顯示「待同步／待核對」，資料完整後才產生總分與燈號。
- 已離會會員不列入現行 KPI 表格。
- 出席由分會 PALMS 報告自動計算。
- 培訓（教育分數）、來賓、一對一、內外部引薦及夢幻引薦金額（提供的引薦金額）均由個人 PALMS 報告依上述期間自動彙整。
